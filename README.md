One debugging haiku, 5-7-5, written by `main.py` to `/output/entry.txt`:

> Print left in the code
> logs my own name at midnight
> the bug wore my name

Entry for the [Seventeen Syllables of Debugging](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) competition on make.fun.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only — no network, no dependencies.
